Course Generator 5.0.0

A major update for trail and ultra-distance planning: more robust route calculations, richer roadbooks, better cutoff management and new exports for Garmin and TrailRace+ PRO.

Route, slope and elevation

  • Slope analysis using a spatial window, reducing artifacts from uneven GPS point spacing.
  • Continuous speed interpolation across the Speed/Slope curve, including steep climbs and descents.
  • Improved elevation processing and cumulative ascent calculation.
  • New per-kilometer statistics for moving pace, ascent and descent.

Roadbook and cutoffs

  • Choose whether a cutoff applies upon arrival at an aid station or after its stop.
  • Calculate cutoff margins and the required moving pace.
  • More mini-roadbook fields: distance from the previous roadbook point, segment ascent/descent, planned times, cutoff, margin, planned station departure and rest duration.
  • The mini-roadbook format editor now exposes the new fields.

GPX and FIT import/export

  • Richer GPX and Garmin FIT route import, including aid/water locations and available timing information.
  • Smaller GPX exports, removing unnecessary numbered names on every track point.
  • Preservation of original waypoint positions independently of their route anchor; fixes finish waypoint displacement.
  • Aid stations are exported as GPX waypoints, including selection-only exports (within the selected range).
  • Exporting GPX no longer marks the editable CGX project as saved.
  • Garmin FIT course export with roadbook point names and food/water icons.
  • New FIT export options: cutoffs, station rests and icons enabled by default; Virtual Partner disabled by default.
  • Experimental barrier Virtual Partner: a no-stop virtual runner with terrain-dependent speed adjusted to hit official deadlines. VP FIT course names receive the suffix " VP".

TrailRace+ PRO and QR codes

  • Generate TR1 codes directly from the current route and roadbook, split into up to three fields of 2,000 characters each.
  • Adaptive encoding to better preserve distance, elevation and aid stations.
  • Choose between bundled adaptive JavaScript, editable local JavaScript and a locally saved copy of the author's script, with optional manual updates.
  • One scannable QR code per field, with large view and PNG saving.

Recent 5.0.0 fixes (November 2026)

  • Roadbook Editor: the five format favorites persist; editing a format and switching rows or closing the window no longer loses the change.
  • Roadbook Editor, Slope: slope fill/border colors persist; saved defaults apply to new tracks while CGX files retain project-specific colors.
  • Garmin FIT: standard and "VP" courses now receive distinct file identifiers so both can coexist on the watch.
  • macOS / Swing stability: Internet connectivity checks no longer block Swing's event thread; HTTP waits are bounded and concurrent probes are skipped.
  • Release notes: fixed loading empty XML preferences when "Stop displaying this dialog box" is unchecked.

Usability and fixes

  • Version 5.0.0 throughout the app; revisit these notes via Help > Release notes.
  • "Stop displaying this dialog box" now saves immediately when the notes window closes, even if the app is later interrupted.
  • Additional regression tests for route exports and round-trip data integrity.

Please note: whether your Garmin watch honors per-record Virtual Partner speeds in FIT courses and how TrailRace+ PRO computes elevation gain still require device-side testing. Use CGX to save an editable project.
