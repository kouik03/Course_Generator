# TrailRace+ PRO TR1 export for Course Generator

## Interface

In **File > Export > Export TrailRace+ PRO TR1 codes**, choose:

1. **Built-in adaptive**: tested adaptive JavaScript shipped as a JAR resource.
2. **Local adaptive**: `~/.course_generator/trailrace/routecode-adaptive-local.js`; initially installed from the bundled adaptive file, editable without recompilation.
3. **Author's local script**: `~/.course_generator/trailrace/routecode-site-local.js`; initially installed from the user-supplied original site version.

Click **Generate the 3 blocks**. Each block is at most 2000 characters and has a copy button. The generator checks TR1 decoding/CRC, capacity (<= 6000 characters), and round-trip checkpoint count. It does not change CGX project state.

The **Import JS** button installs a compatible local JavaScript. **Download JS from site** is a separate, manual action: it connects only to `https://petrrezek.net`, looks for a `routecode` script or compatible inline `RouteCode` definition, validates the `encode/decode` API, prompts before replacing the author's local copy, shows a SHA-256 hash, and backs up the old file. If the site layout or API changes, automatic discovery may fail: the user can still import a file directly.

The embedded JS engine is GraalJS 24.2.2; it does not require Node.js on the end-user machine. The JavaScript context denies Java host class access and I/O, but **only import code from trusted sources**. Downloading is never done automatically. The JavaScript engine requires a compatible JDK 17+; Course Generator users running Java 21/25 are supported.

## Source data / TR1 model

- Route geometry and altitude come from the **currently loaded track** in Course Generator.
- Course name comes from **Track Settings > Track Name**.
- Checkpoints include all MARK/ROADBOOK points, points with cutoff/rest, and the route finish.
- Service letters use the original alphabet `WICGFSBTDR`: `W` for water, `F` for food (food includes water), `C` for crew and `D` for drop bag.
- Cutoffs use `rel` (minutes since course start) when defined. Thus TR1 **version 2** is used for relative cutoffs; some older receivers may not support it.
- TR1 does not have a rest-duration field. The CGX planned pause is not included.
- TR1 names have a strict limit of **24 UTF-8 bytes**. The original JS applies that truncation.
- The `dp` field is cumulative ascent estimated from the existing Course Generator D+ model, scaled from the elevation increments.
- `RouteCode.decode` verifies TR1 CRC and checkpoint count. Actual TrailRace+ PRO device/app decoding must still be checked.
- Geometry and elevation are stored as two separate compressed series. An app that resamples elevation onto geometry vertices before calculating D+ may report a lower D+ than the TR1 profile.
- The adaptive encoder searches fitting candidates with up to three 2000-character fields, and falls back to reference encoding for short routes or when no adaptive candidate fits.

## GPX & original waypoint fidelity

Legacy GPX export wrote a numbered `<name>` for **every** trackpoint, long timestamp strings and many unused Garmin XML schema declarations. The compact export removes only numbered names (retaining actual user-defined names), removes unused namespaces/schema extensions, writes seconds-resolution ISO8601 timestamps and omits decorative XML whitespace. It retains route geometry, elevation, existing time instants to the second, named stations and full/selected route ranges. **Exporting GPX is not saving a CGX project**; modified state is unchanged.

The original raw GPX waypoint location is now separate from the nearest trackpoint anchor in `CgData` and is saved into CGX as optional `WAYPOINTLATITUDEDEGREES` and `WAYPOINTLONGITUDEDEGREES`. Reimporting new GPXs and later exporting preserves those coordinates, including an arrival point that is ~88 m from the route endpoint. Old CGX files saved before this fix do not contain that lost raw position; it cannot be reconstructed without the original GPX.

## Tests

```bash
node tools/test_trailrace_tr1.js
node tools/test_trailrace_tr1.js /path/to/venivicigpx.gpx
mvn clean package
```

The Node smoke test can run without Maven. Maven requires the external GraalJS dependencies and cannot be completed in an environment without Maven Central access. Confirm UI behavior and TrailRace+ decoder on your Mac.

## Script provenance

The bundled scripts are copied from the user-provided site JavaScript and its adaptive extension, rather than generated by translating the encoder to Java. Before redistributing upstream, check the source author's licence/permissions.
